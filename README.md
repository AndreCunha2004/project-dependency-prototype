# Bastão

A relay-style tool to declare, deliver and accept inputs between project disciplines, and to track blocked days.

## Status

Prototype. Internship project, proposal stage.

## Features

- Declare a handoff between two disciplines, with input, planned date and owner
- Record delivery and acceptance
- Flag blocked handoffs and count the days of blockage
- Indicators: percentage of on-time deliveries, blocked handoffs and total blocked days
- Read-only history of every action

## Data

All data is fictional. No real project or client data is used.

## How to run

Open `index.html` in any browser. No installation is needed.
