      Two ways to read a delay

      The same late input is measured from both sides of the handover.

      Origin delay

      Delivery date (or reference date) minus planned date.

      Shows who held the input and for how long. Drives the status.

      Destination blocking

      Delivery date (or reference date) minus needed-by date. Uses the planned date when needed-by is empty.

      Shows how long the next discipline was stopped waiting.

      Example: planned 10/09, needed by 14/09, delivered 17/09. Origin delay 7 days, destination blocking 3 days.

      Indicators by discipline

      Delay is assigned to the origin that held the input; blocking is counted for the destination that waited.
